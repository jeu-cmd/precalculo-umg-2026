# Precálculo · Beto el Numérico

Proyecto web educativo para el curso de Precálculo.

## Estructura

- `index.html` — estructura semántica y vistas de la aplicación.
- `css/styles.css` — estilos y sistema visual editorial.
- `js/data.js` — contenido estructurado de los temas y videotutoriales.
- `js/app.js` — navegación, renderizado e interacción.
- `assets/` — imágenes, logotipos y otros recursos visuales.
- `pdf/` — hojas de trabajo y material descargable.
- `videos/` — archivos de referencia/metadatos; los videos finales se alojarán externamente (por ejemplo, YouTube).

## Desarrollo local

Se puede abrir `index.html` directamente en el navegador para una revisión rápida. Para desarrollo y pruebas más cercanas a producción se recomienda servir la carpeta con un servidor local, por ejemplo Live Server en VS Code.

## Publicación

El proyecto está preparado para GitHub Pages: el archivo de entrada es `index.html` y no depende de un framework ni de un proceso de compilación.

## Flujo de trabajo del equipo

Cada integrante debe agregar o modificar contenido en `js/data.js` siguiendo la estructura existente. Los videos pueden integrarse mediante sus IDs/enlaces de YouTube sin almacenar archivos de video pesados en el repositorio.
